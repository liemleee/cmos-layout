# cmos-layout
Full-custom CMOS schematic,layout,DRC/LVS verification, and post-layout simulation using Cadence Virtuoso and GPDK090

## Projects

### CMOS Inverter

- Transistor-level schematic and transient simulation
- Full-custom layout
- DRC clean
- LVS matched
- RC parasitic extraction
- Pre-layout and post-layout simulation

## Tools

- Cadence Virtuoso
- Spectre
- Assura DRC/LVS/RCX
- GPDK090 90 nm CMOS
